# VoiceMemo アプリ設計書

## 概要

Apple WatchとiPhoneで音声メモを取り、File Provider経由でNextcloud（またはiCloud等）に
Obsidian互換のMarkdownファイルとして保存するアプリ。

## ターゲット

- iOS 17以上
- watchOS 10以上

## アーキテクチャ

```
[Watch App]
  カテゴリ選択 → presentTextInputController（システムDictation）
      ↓ WatchConnectivity (WCSession)
[iPhone App]
  メッセージ受信 → Markdownファイル生成 → File Provider (FileManager) → 保存
```

iPhoneアプリ単体でも同様に動作する（Watch不要）。

## 画面フロー

### Watch側

```
起動
 └─ CategoryPickerView
      ├─ [📔 日記] タップ
      └─ [📷 写真メモ] タップ
           ↓
      presentTextInputController (allowedInputMode: .plain)
           ↓ 入力完了
      WCSession.sendMessage()
           ↓
      完了表示（チェックマーク）→ CategoryPickerViewに戻る
```

### iPhone側

```
起動
 └─ ContentView
      ├─ 初回: SettingsView → UIDocumentPicker でフォルダ選択 → bookmark保存
      └─ CategoryPickerView
           ├─ [📔 日記] タップ
           └─ [📷 写真メモ] タップ
                ↓
           RecordingView（マイクボタン）
                ↓ SFSpeechRecognizer
           MemoBuilder → FileProviderService → 保存完了
```

## 保存ファイル形式（Obsidian互換）

### ファイル名

```
yyyyMMdd_HHmm.md
例: 20260405_1230.md
```

### ファイル内容

```markdown
---
tags: [diary]
created: 2026-04-05T12:30:00+09:00
source: apple-watch
---

#diary ここに音声入力テキスト
```

- `source`は`apple-watch`または`iphone`
- タグはfrontmatterとインライン両方に書く（Dataview対応 + 本文検索対応）

### 保存先ディレクトリ構造

```
<選択したフォルダ>/
└── VoiceMemo/
    ├── 20260405_1230.md
    ├── 20260405_1415.md
    └── ...
```

カテゴリでフォルダは分けない（タグで管理）。

## File Provider実装方針

### 初回フォルダ選択

```swift
// UIDocumentPickerViewController でディレクトリを選択
let picker = UIDocumentPickerViewController(forOpeningContentTypes: [.folder])
picker.delegate = self
// 選択後にsecurity-scoped bookmarkを保存
let bookmarkData = try url.bookmarkData(
    options: .minimalBookmark,
    includingResourceValuesForKeys: nil,
    relativeTo: nil
)
UserDefaults.standard.set(bookmarkData, forKey: "saveFolderBookmark")
```

### ファイル書き込み

```swift
func saveМемо(text: String, category: MemoCategory) throws {
    guard let bookmarkData = UserDefaults.standard.data(forKey: "saveFolderBookmark") else {
        throw FileProviderError.noFolderSelected
    }
    var isStale = false
    let folderURL = try URL(
        resolvingBookmarkData: bookmarkData,
        options: .withoutUI,
        relativeTo: nil,
        bookmarkDataIsStale: &isStale
    )
    guard folderURL.startAccessingSecurityScopedResource() else {
        throw FileProviderError.accessDenied
    }
    defer { folderURL.stopAccessingSecurityScopedResource() }

    // VoiceMemoサブフォルダ作成
    let memoFolder = folderURL.appendingPathComponent("VoiceMemo")
    try FileManager.default.createDirectory(at: memoFolder, withIntermediateDirectories: true)

    // ファイル書き込み
    let filename = DateFormatter.memoFilename.string(from: Date()) + ".md"
    let fileURL = memoFolder.appendingPathComponent(filename)
    let content = MemoBuilder.build(text: text, category: category, source: .iphone)
    try content.write(to: fileURL, atomically: true, encoding: .utf8)
}
```

## WatchConnectivity

### Watch → iPhone 送信データ

```swift
// Watch側
let message: [String: Any] = [
    "text": "音声入力テキスト",
    "category": MemoCategory.diary.rawValue,
    "timestamp": Date().timeIntervalSince1970
]
WCSession.default.sendMessage(message, replyHandler: nil)
```

### iPhone側受信

```swift
func session(_ session: WCSession,
             didReceiveMessage message: [String: Any]) {
    guard
        let text = message["text"] as? String,
        let categoryRaw = message["category"] as? String,
        let category = MemoCategory(rawValue: categoryRaw)
    else { return }

    try? fileProviderService.saveMemo(text: text, category: category)
}
```

## MemoBuilder

```swift
struct MemoBuilder {
    enum Source: String {
        case appleWatch = "apple-watch"
        case iphone     = "iphone"
    }

    static func build(text: String, category: MemoCategory, source: Source) -> String {
        let now = Date()
        let isoDate = ISO8601DateFormatter().string(from: now)
        return """
        ---
        tags: [\(category.rawValue)]
        created: \(isoDate)
        source: \(source.rawValue)
        ---

        #\(category.rawValue) \(text)
        """
    }
}
```

## Settings（保存先管理）

- `UserDefaults`にsecurity-scoped bookmarkを保存
- SettingsViewに「保存先フォルダ: /Nextcloud/VoiceMemo」と現在のパスを表示
- 「変更」ボタンで再度DocumentPickerを開く
- bookmarkがstaleになったときは自動で再選択を促すアラート
